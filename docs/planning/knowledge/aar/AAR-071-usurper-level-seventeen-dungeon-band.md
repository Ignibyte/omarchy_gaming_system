## What happened

- Implemented external Usurper rules/state/cartridge v22 with exact Level 17
  records 160–169, draw-free switching across levels 1–17, preserved
  `Random(170)` rejection order, source-derived strength 21/defence 10/63 HP,
  Level 17 retreat damage, bounded `option_q`, one fixed provider action,
  signed presentation, fixtures, provenance, compatibility docs, and tests.
- Ratcheted the platform's game-neutral trusted-QML regression from nineteen
  old to twenty current controls, recursively requiring one actual delegate per
  node and retaining real pointer/Return activation coverage.
- Full external validation passed 118 Rust tests, strict lint/docs,
  authenticated source/provenance, six QML cases, seventeen signed screens,
  and provider-backed local play. The production provider's fixed fifteen-case
  TLS/replay/fault/callback corpus passed twice across restart, and the complete
  platform diff gate passed before documentation completion and again after
  OpenWiki/pipeline archival, with final matching receipt
  `61a39516d74c6ff20c871d76f6e3931c82b515d98bf8c196b65cffe6651d89a5`.
- The user's duplicate/inert-button observation remained a release blocker
  until live v22 proof. Compositor-delivered Return/Tab input advanced revisions
  0–6 exactly once; both dungeon views had 20 buttons, 20 unique IDs, and 20
  unique actions, while combat had five of each and showed a Level 17 Rabid
  hound at 63/63 HP. The verified window remains open on workspace 8.
- The Codex Security scan reviewed all 17 source-like files with zero
  reportable findings and no deferred coverage. Two developer-local capability
  and render-retention observations were policy-excluded; a trace-exhaustion
  candidate became a correctness fix and targeted post-scan delta review.
- Hand architecture and OpenWiki now describe rules v22, Level 17, `option_q`,
  boundary record 160, and the 19-to-20 delegate proof without implying
  production registration, admission, deployment, or publication.

## Failures captured

- `BF-omarchy-gaming-system-usurper-rng-trace-bound-exhaustion-001`: the
  original 64-draw retention cap could exhaust during a valid Level 17
  rejection loop. RNG state 6 reproduced 64 rejected draws and identical retry
  failure; the theoretical Level 17 exhaustion probability was about 3.08%.
  The bound is now 256, an 82-draw deterministic progression test reaches
  record 168, and a maximum 256-draw provider state remains below 32 KiB.
- No new ID: the first focused Level 17 live profile expected a successful
  retreat but the source-valid sequence died. The existing phase-transition
  prevention rule worked as intended; the test/corpus now asserts death and
  `reenter`, and a dedicated Level 16 regression proves the older survival path
  was not accidentally rewritten.
- No new ID: the first post-inspection JSON assertion compared numeric v22
  values as strings. Inspecting the manifest shape corrected the assertion
  before it was used as evidence.
- No new ID: the first OpenWiki update was intentionally left interrupted when
  claims inspection showed the hand architecture still stopped at Level 16.
  The architecture source was reconciled first, then a new lifecycle superseded
  the interrupted run and completed.

## Prevention rules captured

`PR-omarchy-gaming-system-size-rejection-traces-against-valid-tail-risk-001`:
when a bounded trace retains every draw from an unbounded rejection loop,
quantify the implemented tail-exhaustion risk, test a deterministic long valid
run near that risk, and prove the maximum retained serialized state remains
inside its transport ceiling.

## Architecture decisions

No new ADR was required. ADR-0002's boundary held: the separate provider owns
Usurper data, rules, RNG, state, and revisions; OmarchyGS validates and renders
only inert signed presentation. `option_q` is a bounded external view field and
the sole platform source edit is the game-neutral 19-to-20 QML regression. The
256-draw trace remains bounded and fits the current provider envelope, but much
deeper future bands should compact or redesign trace retention instead of
indefinitely widening the vector.
